Equitable access to green and public space is part of SDG 11.7, but up-to-date maps of *public* green spaces are rare, and existing approaches often depend on proprietary software.

This work builds a fully reproducible workflow using only Sentinel-2 imagery, OpenStreetMap data and open-source Python libraries, covering data acquisition, preprocessing, deep learning and evaluation.

Read the paper: [City and Environment Interactions (2026)](https://doi.org/10.1016/j.cacint.2026.100514).
