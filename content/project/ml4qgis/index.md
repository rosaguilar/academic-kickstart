**ML4QGIS** (*Machine Learning for QGIS*) brings machine learning for image classification and regression into QGIS, so geospatial analysts can train and apply models without writing code.

* Available in the [official QGIS plugin repository](https://plugins.qgis.org/plugins/ml4qgis/) (version 0.4.0, August 2026), with more than 6,000 downloads.
* Open source under GPL-3.0 on [GitHub](https://github.com/rosaguilar/ml4qgis).
* Introduced at FOSS4GNL 2025 and used in the FOSS4G 2026 workshop *GeoAI Level Up*, including YOLO object detection inside ML4QGIS.

Feedback, issues and pull requests are welcome.
